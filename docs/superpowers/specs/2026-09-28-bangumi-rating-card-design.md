# Bangumi Rating Card 设计说明

## 目标

把 `qq-bangumi-bot-leo` 中已经存在的 Bangumi 风格评分卡独立成一个纯静态网页工具。

本项目不重新设计评分卡，也不凭印象模仿 Bangumi。最终评分卡直接沿用旧仓库 `astrbot_plugin_bangumi_anime/templates/bangumi_subject.html` 的结构、尺寸、颜色、评分柱状图和 `rate_emo.gif` 表情逻辑；编辑页也遵照 Bangumi 本身的视觉语言。

## 使用流程

1. 用户输入 Bangumi 条目 ID，或粘贴 `bgm.tv/subject/<id>` / `bangumi.tv/subject/<id>` 链接。
2. 浏览器调用 Bangumi 新公开 API `GET https://api.bgm.tv/v0/subjects/{id}`。
3. 标题、日期、话数、ID、封面直接取 API 数据，不提供手工编辑。
4. 平均分、排名、1～10 分人数默认同时从 Bangumi 导入。
5. 用户可修改任意一档评分人数；修改后页面立即重算总票数、平均分、评分描述、表情档位和柱状图。
6. 提供“恢复 Bangumi 评分”操作，把评分区恢复到最近一次成功载入的 Bangumi 原始数据。
7. 右侧/下方实时显示最终评分卡，并可导出 PNG。

## 页面结构

页面仍是单页静态网页，不引入前端框架。

### 顶部

- 工具标题。
- Bangumi 条目 ID / 链接输入框。
- “载入 Bangumi”按钮。
- 简短状态提示，显示载入成功、条目不存在、网络失败等。

### 条目信息区

只读显示：

- 标题：优先 `name_cn`，没有时使用 `name`。
- 日期：`date`。
- 话数：`eps`。
- ID：`id`。
- 封面：优先使用较高分辨率封面 URL。

这些字段始终以 Bangumi 返回值为准，不提供单独输入框。

### 评分编辑区

- 显示当前平均分、排名、总票数。
- 1～10 分各一个数字输入框。
- 初次载入时使用 Bangumi `rating.count`。
- 任意输入变化后即时重算：
  - 总票数 = 1～10 分人数之和；
  - 平均分 = 加权平均；
  - 柱状图高度沿用旧工具算法：相对最高人数按 92% 最大高度缩放；
  - 评分描述沿用旧工具阈值；
  - 表情档位沿用旧工具 `score1`～`score10` 逻辑。
- 提供“恢复 Bangumi 评分”按钮。

排名默认从 Bangumi 导入并保持原值；手改评分人数不会伪造新的站内排名。

## 最终评分卡

以旧仓库 `bangumi_subject.html` 为基准直接迁移：

- `#capture` 固定 620px 宽；
- 标题、元信息、封面和右侧评分区布局保持一致；
- 评分数字保持 Bangumi 粉色；
- `rate_emo.gif` 继续使用精灵图背景定位；
- 10～1 分柱状图保持旧 CSS 与 92% 缩放逻辑；
- `Bangumi Anime Ranked:`、票数文本、排名样式保持旧卡片形式。

只把 Jinja 模板变量替换为浏览器 DOM 更新，不改视觉设计。

## 编辑页视觉

编辑页不采用通用“现代管理后台”样式。视觉语言取自 Bangumi：

- 白底和浅灰页面背景；
- Bangumi 粉色作为链接、按钮和重点色；
- 小字号正文和灰色辅助文字；
- 浅灰分隔线与紧凑区块标题；
- 表单控件保持轻量、窄边框、低圆角；
- 不使用大面积渐变、玻璃拟态、大圆角卡片、夸张阴影。

最终评分卡与编辑控件视觉上属于同一套站点风格，但最终评分卡本身严格以旧实现为准。

## 技术结构

保持最小文件结构：

- `index.html`：页面结构与评分卡 DOM。
- `style.css`：编辑页样式 + 从旧评分卡迁移的 CSS。
- `script.js`：ID 解析、Bangumi API 请求、状态管理、评分重算、DOM 更新、PNG 导出。
- `assets/rate_emo.gif`：从旧仓库迁移的表情精灵图。
- 可选的本地字体资源仅在确有必要时加入；优先使用浏览器常见字体回退，避免为了一个静态页携带十几 MB 字体。

不使用构建工具，不要求 Node.js，不要求服务器；下载仓库后可直接打开 `index.html` 使用。

## API 与失败处理

使用 Bangumi 新公开 API：

`GET https://api.bgm.tv/v0/subjects/{id}`

公开 GET 接口支持浏览器跨域访问。

失败时：

- 非法 ID / 链接：在输入区显示提示，不改变当前卡片。
- 404：提示未找到条目。
- 网络错误 / API 异常：提示载入失败，并保留当前数据。
- 缺少中文标题时回退到原名。
- 缺少封面时显示旧卡片的 `NO IMAGE` 占位。
- 缺少评分时评分人数初始化为 0，平均分显示 `--`。

## PNG 导出

导出目标只包含最终评分卡 `#capture`，不包含编辑区。

实现优先选择浏览器端 DOM 转图片方案；若第三方库会导致直接双击 `index.html` 时依赖网络，则把所需脚本随仓库保存，避免 CDN 成为运行前提。

## 验证

至少人工验证以下情况：

1. 正常动画条目：标题、日期、话数、封面、平均分、排名、10 档评分人数与 Bangumi API 一致。
2. 粘贴纯数字 ID 和完整 Bangumi 条目链接都能识别。
3. 修改某一档人数后，总票数、平均分、描述、表情和柱状图即时变化。
4. “恢复 Bangumi 评分”能恢复原始评分分布。
5. 无中文标题、无封面、无评分等缺省情况不会破坏布局。
6. PNG 导出尺寸和视觉与页面中的评分卡一致。
7. 直接以本地文件方式打开 `index.html` 时，核心功能不依赖本地开发服务器。
